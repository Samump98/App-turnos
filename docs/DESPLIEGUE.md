# Despliegue en Streamlit Community Cloud

1. Sube el repositorio a GitHub (con `app.py` en la raíz y `requirements.txt`).
2. En https://share.streamlit.io inicia sesión con GitHub y pulsa **Create app**.
3. Elige repositorio, rama y archivo principal `app.py`, y despliega.
4. Cada `git push` redespliega automáticamente.

## Notas
- El historial es de sesión: usa Exportar/Importar para conservarlo.
- Para ejecutar en local: `streamlit run app.py`.
